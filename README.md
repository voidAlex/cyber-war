# 赛博战争模拟器 (Cyber War Simulator)

> 一款以"自然语言交互"为核心、由大语言模型（LLM）驱动的硬核大战略与态势推演游戏。

## 项目简介

赛博战争模拟器是一款创新的战争策略游戏，玩家扮演最高统帅，通过自然语言与 AI 参谋长交互，在战争迷雾中进行盲盒博弈。

### 核心特性

- **自然语言交互**：告别传统鼠标微操，通过自然语言下达宏观战略指令
- **WEGO 同步回合制**：以"天/战役阶段"为单位推进，还原真实的统帅部运作节奏
- **多 Agent 层级博弈**：参谋长、战区司令、敌方/盟友统帅、导演部等多角色 AI 协同
- **战争迷雾系统**：情报置信度展示、情报半衰期、残影系统、战略欺骗
- **战役插件化**：通过 ZIP 文件导入导出战役包，支持自定义剧本

## 技术架构

- **前端**：高信息密度的全息指挥控制台，数据表格、态势沙盘、自然语言对话
- **后端**：回合状态结算、多 Agent 调度、流式对话输出（仅 LLM API 转发）
- **存储**：OPFS 持久化（JSON 为唯一真相源），支持 ZIP 导入导出

### 栀技术栈

- 纯前端业务逻辑（浏览器 OPFS 存储）
- 后端仅负责 LLM API 转发（支持多供应商路由）
- 多 Agent 协同与 Agentic Search 技术

## 游戏机制

### 回合流程

1. **规划期**：观察沙盘，与参谋长 AI 对话下达指令
2. **指令确认**：参谋长拦截模糊指令，沙盘预演虚线，玩家确认后入队
3. **集中结算**：点击"推演下一天"，双方计划锁定，导演部裁定战果
4. **战报分发**：流式战报输出，沙盘更新，情报半衰

### Agent 体系

| Agent | 职责 |
|-------|------|
| 参谋长 (玩家侧) | 指令明确化转换、风险提示 |
| 战区司令 | 宏观指令拆解、人格决策 |
| 敌方/盟友统帅 | 独立阵营战略、外交响应 |
| 导演部 (裁判) | 最终裁定权、随机事件、战报润色 |

## 开发状态

当前处于 MVP 开发阶段，预计 12-16 周完成。

### 里程碑

- **M1 (第 1-3 周)**：项目骨架 + 状态机 + OPFS 存储底座
- **M2 (第 4-6 周)**：命令握手 + 物理引擎 + 沙盘基础渲染
- **M3 (第 7-10 周)**：多 Agent 编排 + 导演部 + 战报系统
- **M4 (第 11-13 周)**：情报/外交/ZIP 战役包 + 验收测试

## 使用说明

### API Key 要求

本项目不提供 LLM API 服务，玩家需自行输入 API Key：

- 后端仅转发请求，不存储 API Key
- 代码开源，可供审计
- 支持多种 LLM 供应商（OpenAI、Claude、DeepSeek 等）

### Safari 用户注意

Safari 浏览器在 7 天无交互后可能清除 OPFS 数据，建议：
- 定期导出存档
- 推荐使用 Chrome/Edge/Firefox
