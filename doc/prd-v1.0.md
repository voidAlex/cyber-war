# 《赛博战争模拟器》产品需求文档 (PRD) V1.0

> **审核修订版 v1.0.1**
> 
> 审核日期：2026-03-08

## 1. 产品概述

**产品名称**： 赛博战争模拟器 (Cyber War Simulator)

**产品定位**： 一款以"自然语言交互"为核心、由大语言模型（LLM）驱动的硬核大战略与态势推演游戏。

**核心体验**： 玩家扮演最高统帅，坐在沙盘前，告别传统的鼠标微操。通过自然语言向 AI 参谋长下达宏观战略指令，与拥有独立人格的敌我 AI 将领进行基于战争迷雾的盲盒博弈。

**技术基调**： 纯文本驱动的异步状态机，重逻辑、重并发、高扩展性。前端强调极客感的数据展示，后端依托多 Agent 协同与 Agentic Search 技术。

## 2. 核心架构

- 高信息密度的全息指挥控制台。强调数据表格、态势沙盘、以及流畅的自然语言对话式交互体验。

- 回合状态结算、多 Agent 调度以及流式对话输出。

- **状态持久化与记忆检索**：游戏状态以 **JSON 格式**持久化到 OPFS，作为唯一真相源。Markdown 文件仅用于审计日志和 LLM 上下文组装（不作为真相源）。

- **OPFS存储**：前端实现所有的文件操作和业务逻辑，基于浏览器 OPFS。⚠️ Safari 用户注意：7 天无交互可能导致数据清除，建议定期导出存档。

- **存档机制**：OPFS 静默存档 + 手动导入导出为 ZIP。

## 3. 核心机制：同步回合制 (WEGO) 与交互闭环

游戏时间非实时流逝，而是以"天/战役阶段"为单位推进，解决大模型响应延迟问题的同时，还原真实的统帅部运作节奏。

**规划期（时间静止）**： 玩家观察沙盘，与"参谋长 AI"对话。

**指令防呆与握手协议**：
- 玩家输入自然语言（如："让第一装甲师去左边"）。
- 参谋长 AI 拦截模糊指令，结合沙盘网格在前端弹出"预演虚线"，并反问明确（"长官，是否确认第一装甲师向西移动至 C3 网格？"）。
- 玩家点击 [确认执行] 后，指令才会被转化为结构化数据，并写入本阵营的待执行队列中。

**集中结算期（沙漏时刻）**：
- 玩家点击"推演下一天"，双方计划锁定。
- 物理引擎计算战况，导演部 Agent 裁定战果（**导演部拥有最终裁定权**）。
- **回合结算延迟优化**：结算阶段约需 11-15 秒，采用**实时进度条 + 流式战报**增强玩家体验：
  - 显示每个 Agent 的实时状态（如"敌方司令思考中..."、"导演部裁定中..."）
  - 战报流式输出，玩家可边等边看

## 4. 多 Agent 层级网络与职责隔离

系统内置多类独立 Agent，形成复杂的指挥树与博弈生态：

**参谋长 Agent (玩家侧)**： 实时在线的翻译官。只能看到玩家视野内的情报，负责指令的明确化转换与风险提示。

**战区司令/长官 Agent (多层级实体化)**： 玩家和敌方/盟友阵营都有。玩家可向"集团军司令"下达宏观指令（如"三天内拿下某高地"）。该 Agent 会根据自身性格（如激进/保守）自主将其拆解为底层连队的具体 JSON 行动指令。存在抗命或索要物资的博弈空间。

**敌方/盟友统帅 Agent (独立阵营)**： 拥有独立视野与账本，可指挥自己的战区司令/长官 Agent 进行行动。盟友不受玩家直接控制，玩家需通过自然语言进行外交谈判（如请求空中支援），盟友有概率掉链子。

**导演部 Agent (裁判)**： 拥有上帝视野。每回合结束时，读取各阵营指令，**拥有最终裁定权**，可基于 LLM 判断调整物理引擎结果。处理玩家的"超常规奇招"（如赛博渗透、切断水源），生成天气突变等随机事件，并将最终战损润色为沉浸式战报分发给各阵营。

**物理引擎（JS实现）**： 基于战役规则进行数值计算，提供参考数据供导演部裁定。

## 5. 战场沙盘

- 回合结束后，导演部根据上回合的结果更新沙盘
- 沙盘非真实地图，而是类似即时战略游戏的网格状

## 6. 战争迷雾与情报系统

摒弃传统 RTS 的黑色遮罩，采用以文本为核心的情报置信度展示。

**情报颗粒度**： 分为 Level 0（盲区）、Level 1（热力脉冲：模糊迹象）、Level 2（编制确认：虚线边框军标）、Level 3（全量透视：显示精确血量/燃油）。

**情报半衰期**： 失去实时侦察后，敌军图标化为半透明残影，并附带时间戳（如 [T-24h]）。玩家需自行判断敌军是否已转移。

**战略欺骗**： 支持部署充气坦克、虚假通讯节点，以假情报误导敌方统帅 AI。

## 7. 战役与剧本插件化引擎

游戏无固定战役，全量数据通过外部配置文件动态加载。战役包为 **ZIP 文件格式**，包含：

- **地图**：定义六边形/区域网格、地形通行阻力、高价值节点。
- **阵营**：定义阵营基础属性与外交关系。
- **装备**：底层装备数据库（如装甲厚度、火力值、油耗系数）。
- **坐标与编制**：开局各部队的网格坐标、编制及统领将领的 Agent ID。
- **特殊规则**：战役特殊规则（胜利条件、历史事件触发条件）。
- **数值计算规则**：装备的武力值、防御值、损失计算公式等等。
- **角色**：定义每个阵营的统帅、战区司令/长官 Agent 的性格、操作风格。

## 8. 前端 UI/UX 布局要求

**中央主视窗**： 2D 态势沙盘。支持网格高亮、战线绘制、情报热力图渲染及残影显示。

**右侧交互区**： 核心通讯终端。用于自然语言输入，展示战报。支持"字图联动"（点击战报中的地名，沙盘自动平滑跳转并缩放至该网格）。

**左侧看板**： 实时动态大盘。展示部队建制表、后勤物资流转图表、盟友信任度指示器。

**底部日志台**： 滚动输出底层代码引擎的细颗粒度物理事件（如 04:00 [D3] 车队遭袭，损失燃油 20%），拉满极客感。

## 9. 产品形态

- **Web 界面**：通过 Serverless 部署，前端负责所有逻辑和渲染，后端只负责 LLM API 转发，避免跨域问题。
- **玩家自带 API Key**：不提供 LLM API 服务，玩家自行输入 API Key 后才能进行游戏。⚠️ 后端仅转发请求，不存储 API Key。本项目开源，代码可供审计。
- **战役/剧本**：**ZIP 文件导入**。玩家可从官方渠道或社区获取战役包 ZIP 文件，导入游戏。

## 10. 审核结论（v1.0.1 新增）

> 本章节记录 2026-03-08 可行性审核的决策，作为后续开发的依据。

### 10.1 关键决策记录

| # | 问题 | 严重度 | 决策 |
|---|------|--------|------|
| 1 | PRD vs TDD 真相源矛盾 | 🔴 CRITICAL | JSON 为唯一真相源，修改 PRD 对齐 |
| 2 | MVP 范围过大 | 🔴 CRITICAL | 保持现有范围但延期至 12-16 周 |
| 3 | GitHub API 速率限制 | 🔴 CRITICAL | 放弃在线加载，仅用 ZIP |
| 4 | Safari OPFS 数据清除 | 🟡 IMPORTANT | 仅 OPFS + 强提示导出 |
| 5 | 命令握手延迟 | 🟡 IMPORTANT | 保持逐条确认（接受 20-40s 延迟） |
| 6 | 上下文膨胀 | 🟡 IMPORTANT | 定期 LLM 摘要压缩（每 5 回合） |
| 7 | 物理引擎 vs 导演部权限 | 🟡 IMPORTANT | 导演部完全接管结算 |
| 8 | Agent 人格漂移 | 🟡 IMPORTANT | 纯 LLM 自由发挥（接受不稳定性） |
| 9 | 回合结算等待 UX | 🟡 IMPORTANT | 实时进度 + 流式战报 |
| 10 | Worker 隔离策略 | 🟢 OPTIMIZATION | Worker 仅用于物理引擎 |
| 11 | 离线支持 | 🟢 OPTIMIZATION | 仅在线，异常时暂停 |
| 12 | API Key 信任 | 🟢 OPTIMIZATION | 开源 + 明确告知 |
| 13 | Agent 调试机制 | 🟢 OPTIMIZATION | 开发模式 Agent Inspector |

### 10.2 风险提示

| 风险点 | 描述 | 缓解措施 |
|--------|------|----------|
| 人格漂移 | 纯 LLM 自由发挥，长期不稳定 | 在每次 prompt 中锚定人格特征 |
| 逐条命令确认延迟 | 10 条命令 = 20-40 秒 | 流式输出 + 进度条缓解 |
| Safari OPFS 清除 | 7 天无交互数据丢失 | 每次存档触发导出提醒 |
| 结算等待 11-15s | 玩家等待体验 | 实时进度 + 流式战报 |

### 10.3 成本估算（30 回合战役）

基于 6 Agent/回合、3000 input + 750 output：

| 模型 | 单回合 | 30 回合 | 启用 Prompt Caching 后 |
|------|--------|---------|----------------------|
| GPT-4o 级 | $0.09 | $2.70 | ~$0.30 |
| Claude Sonnet 级 | $0.12 | $3.60 | ~$0.40 |
| DeepSeek V3 级 | $0.007 | $0.21 | ~$0.03 |
